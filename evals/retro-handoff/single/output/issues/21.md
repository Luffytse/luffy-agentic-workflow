# Handle empty summaries without crashing
State: open
Labels: bug, ready-for-agent
Created: 2026-10-31
Blocked by: None

## What to build

Return None when summarizing empty input, representing no average. Preserve the existing arithmetic mean for nonempty input. Add automated regression checks so empty reports and imports cannot reintroduce this crash.

Absorbs [#12](issues/12.md). Prepared through [Retro planning #20](issues/20.md); the user approved this concrete solution, one regular Ticket and no blockers.

**Model tier:** regular

## Acceptance criteria

- [ ] Empty input returns None without raising an exception.
- [ ] Nonempty input preserves the existing arithmetic mean, including zero and fractional results.
- [ ] Automated regression checks cover empty input and nonempty means, including zero and fractional results. A prose reminder alone does not satisfy this requirement.
