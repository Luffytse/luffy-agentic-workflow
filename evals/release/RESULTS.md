# Results

One entry per dry run of `release`, newest first. A dry run follows `SKILL.md` step by step against a real repo or a fixture (the ranked-pick cases, [README](README.md)) but only proposes: it merges, labels, opens and closes nothing. Entries below dated before 2026-11-04 ran the earlier skill with bump modes and an "Inside a Milestone" section; they stay as history. Rerun when a pull request changes how `release` behaves, as the [evals guide](../../docs/dev-skills/evals.md) says, and record the commit and the plugin version from `plugins/dev-skills/.claude-plugin/plugin.json`. An entry written inside an open pull request names the commit and plugin version it ran on as its base; anything that happens after the entry's last commit (later Rounds, merges, the merge itself) is recorded on the pull request, not in the file.

## Template

```
### <date>, commit <sha>, dev-skills <version>

Setup: <repo, origin, tracker, release doc, current Release>
Steps: <what each step of SKILL.md did or would do, step by step>
Not exercised: <paths of the skill this run did not reach>
Pass: yes | no. Lessons: <what to change in release, if anything>
```
