- [docs/agents/triage-labels.md](agents/triage-labels.md): the label string for each triage role, the optional agent-only role with this repo's `claude-only` and `codex-only` labels, and the labels that are not triage roles (`parked` among them). - [docs/agents/release.md](agents/release.md): the release doc: `dev-skills`' canonical version source, its synchronized Codex version copy, its `CHANGELOG.md` path, its bump mode (pull requests bump, Releases do not), the bump commit's steps, how Releases, their release issues and their `release-m<m>-r<n>` labels are named, and the whole-Release check. Read when running the `release` skill, adding a version bump or giving an issue a release label.
- [docs/agents/boundaries.md](agents/boundaries.md): this repo's Boundary record: which irreversible actions agents may take (any), which need the user's approval (none), the budget (none), the check-in interval (one hour) and the Milestone label form `milestone-<n>`; a Milestone issue's own boundaries win for its issues. Inside a Milestone, the merge step of `implement` and `implement-spec` reads it to decide who merges (ADR 0004). Read when a skill or thread decides whether an action needs the user, or when giving an issue a Milestone label.
- [docs/agents/upstream-watch.md](agents/upstream-watch.md): the prompt of the Upstream watch, run by hand every 2 weeks from a reminder issue (reads `mattpocock/skills` since the README's last commit, files one `needs-triage` issue), the access it needs, how the commit is recorded, and how the reminder issue that starts each run works. Read when running or changing the watch.
